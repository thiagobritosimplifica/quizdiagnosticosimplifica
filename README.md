# Site do Diagnóstico do Atendimento Comercial — Simplifica

A aplicação fica na pasta [`diagnostico-comercial/`](diagnostico-comercial).

```bash
cd diagnostico-comercial
npm install
npm run build
npm start
```

- Site: http://localhost:3000
- Painel da equipe: http://localhost:3000/admin

Os leads são gravados numa planilha do Google Sheets. O passo a passo da conexão,
das variáveis de ambiente e do deploy está em
[`diagnostico-comercial/README.md`](diagnostico-comercial/README.md).
